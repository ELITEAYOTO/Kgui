# Documentation Kgui 2.0

Kgui 2.0 est le moteur de menus générique de Volkaria. Il cible en priorité
KHope/PandaSpigot 1.8.8 et reste utilisable sans Kfaction. Kfaction 2.3 et
KjobsUltimate s'y branchent comme extensions optionnelles propriétaires de
leurs données et de leurs actions.
